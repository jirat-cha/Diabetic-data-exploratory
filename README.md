# Diabetic-data-exploratory
This repository contributes as a part of an assignment in DES432 Statistics and Data Modeling course. <br>
The dataset used in the analysis is available in https://www.kaggle.com/datasets/iammustafatz/diabetes-prediction-dataset <br>
Code for data loading, cleaning, EDA, visualization, and inferencing is in a single .ipynb file

## Setup

1. Download .ipynb file and open it in the ide/services that supports ipynb such as vscode or Google Colab. <br>
2. If you are doing it in local, install all necessary packages. <br>
```pip install kagglehub pandas matplotlib seaborn numpy``` <br>
If you are using Google Colab, it is already came up with those packages. <br>
3. Run all code blocks.
